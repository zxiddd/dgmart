Service won't start:
→ Check logs: tail -f /var/log/supervisor/[service].err.log
→ Restart: sudo supervisorctl restart [service]

Database connection failed:
→ Check .env file exists
→ Verify DATABASE_URL is correct
→ Test: cd /app/backend && node -e "require('./src/config/db').query('SELECT 1')"

Frontend can't reach backend:
→ Check .env.local files exist
→ Verify NEXT_PUBLIC_API_URL=http://localhost:5000/api
→ Restart frontend: sudo supervisorctl restart admin-dashboard

Port already in use:
→ Find process: lsof -i :[port]
→ Kill process: kill [PID]
→ Or use different port
